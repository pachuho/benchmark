# Benchmark
본 프로젝트는 IoT 디바이스 통신 과정을 다룹니다. 

IoT 3rd-party 라이브러리를 거치지 않고 대표적인 통신 라이브러리를 이용해 디바이스를 직접 조회 / 제어하며

전반적인 앱 개발 과정에서 발생하는 고민이나 이슈들을 기록하며 개선합니다.

## 주요 기능
- 프로젝트 구성
  - 기능별 모듈 구성
  - 모듈별 참조 라이브러리 구성
